# 功能需求分析

Huster 今天吃什么小程序主要围绕“校园食堂菜品评价”展开，系统功能分为七大模块，共覆盖从菜品浏览、评价发布到用户管理的全部核心流程，具体如下：

------

## 1. **首页功能（Home）**

- 展示今日推荐菜品，其中展示热门/高分菜品，避雷榜（低分菜品，可选），新品榜单（可选）
- 提供搜索入口
- 提供进入食堂列表的入口

**作用：**为用户提供快速找到“今天吃什么”的方式。

------

##  2. **食堂浏览功能（Canteen）**

- 查看所有食堂列表
- 查看某食堂下的全部菜品
- 菜品按评分、热度、评价数量排序
- **用户可提交“建议新增菜品”**

待扩展功能：

+ 食堂地图
+ 按距离显示食堂列表

**作用：**帮助用户快速了解各食堂的菜品情况，并补充缺失菜品。

------

## 3. **菜品详情功能（Dish Detail）**

- 查看菜品图片、名称、均分、热度、评价数
- 查看图文评价列表
- 按时间或热度排序评价

**作用：**提供菜品的“真实评价信息”，帮助用户避雷或选择高质量菜。

------

##  4. **评价功能（Review）**

- 发布评价：评分 + 文本 + 图片
- 上传评价图片（可选）
- 点赞他人评价
- 删除自己的评价

**作用：**让用户分享真实体验，构成系统主要内容来源。

------

## 5. **搜索功能（Search）**

- 按菜品名称搜索
- 查看搜索结果的菜品详情

**作用：**快速定位目标菜品。

------

## 6. **用户中心功能（User Center）**

- 展示用户头像与昵称
- 查看自己发布过的评价
- 删除自己的评价
- 可查看点赞记录（可选）

**作用：**提供个人历史内容管理。

------

## 7. **登录与基础系统功能（System / Login）**

- 微信授权登录
- 自动获取 openid 并创建用户
- 使用云数据库存储菜品、评价、食堂等数据
- 使用云存储保存评价图片

**作用：**保证系统正常运行、用户身份唯一、数据可控。



本系统的功能需求涵盖了用户浏览、选择、评价菜品的完整流程，构建了以“真实评价”为核心的校园食堂菜品推荐平台。功能模块清晰，逻辑闭环，满足学生用户日常就餐选择的主要需求并提供有效扩展（如新增菜品建议功能）。
