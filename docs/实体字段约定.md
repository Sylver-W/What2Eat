## 实体字段约定

有需要可以增加字段，同一名称

### 1 canteens

| 字段名            | 类型          | 示例                                | 说明                                                         |
| ----------------- | ------------- | ----------------------------------- | ------------------------------------------------------------ |
| `canteenId`       | Number        | 11                                  | 业务主键，食堂唯一标识，用于与菜品等实体建立关联。           |
| `name`            | String        | "百惠园食堂"                        | 食堂名称，用于展示、搜索等。                                 |
| `image`           | String（URL） | "cloud://.../baihuiyuan.jpg"        | 食堂展示图片，存储于云存储，首页/列表页使用。                |
| `rating`          | Number        | 4.6                                 | 食堂总体评分，可由菜品评分或用户提交的评价计算。用于排序与展示。 |
| `location`        | String        | "紫菘学生公寓入口处"                | 食堂地理位置，用于详情页展示及导航定位。                     |
| `isOpen`          | Boolean       | true                                | 食堂是否营业。管理端可更改，用户端用于实时展示。             |
| `businessHours`   | String        | "早中餐6:50–14:00, 晚餐16:50–23:00" | 营业时段说明，展示给用户。若未来精细化可设计为结构化字段。   |
| `featuredDishes`  | Array<String> | ["日式咖喱鸡排饭","卤肉饭"]         | 特色菜品名称数组（仅展示用，非强关联）。                     |
| `featuredDisplay` | String        | "日式咖喱鸡排饭、卤肉饭"            | 特色菜品展示字符串，用于减少前端处理逻辑。                   |
| `description`     | String        | "百惠园食堂位于……"                  | 食堂总体描述，用于详情页文本介绍。                           |

### 2 dish

| 字段名        | 类型          | 说明                                               |
| ------------- | ------------- | -------------------------------------------------- |
| `_id`         | String        | 云数据库自动生成主键                               |
| `dishId`      | Number        | 业务主键，自增或手动维护                           |
| `name`        | String        | 菜品名称                                           |
| `canteenId`   | Number        | 外键（对应食堂实体）                               |
| `canteenName` | String        | 冗余字段，加快展示，不必再次查食堂集合             |
| `images`      | Array<String> | 多张图片                                           |
| `price`       | Number        | 单价，保留两位小数                                 |
| `tags`        | Array<String> | 标签用于搜索与分类，如“招牌”“粉面”“川味”（可不用） |
| `rating`      | Number        | 平均评分（0-5），由评论模块计算                    |
| `ratingCount` | Number        | 总评分数                                           |
| `description` | String        | 介绍信息                                           |
| `isAvailable` | Boolean       | 上架（true）下架（false）                          |
| `favourCount` | Number        | 收藏数                                             |

### 3 comment

| 字段名         | 类型          | 示例               | 说明                                                 |
| -------------- | ------------- | ------------------ | ---------------------------------------------------- |
| `_id`          | String        | "comment_001"      | 云开发自动主键。                                     |
| `commentId`    | Number        | 1                  | 评论业务主键                                         |
| `dishId`       | Number        | 11                 | 评论对应的菜品 ID（关联 Dish 实体）。                |
| `dishName`     | String        | "日式咖喱鸡排饭"   | 冗余字段，用于用户端快速展示。减少额外查询。         |
| `canteenId`    | Number        | 3                  | 此评论所属食堂（间接通过菜品获得，存冗余便于查询）。 |
| `userId`       | String        | "wx_openid_abc123" | 用户唯一标识（OpenID）。                             |
| `userAvatar`   | String        | 云端 URL           | 用户头像（用于展示，冗余）。                         |
| `userNickname` | String        | "小明"             | 用户昵称展示用（冗余）。                             |
| `rating`       | Number        | 5                  | 用户对菜品的评分（1–5）。                            |
| `content`      | String        | "味道不错…"        | 评论文字内容。                                       |
| `images`       | Array<String> | 多图               | 评论附带图片数组（0–9张均可）。                      |
| `likeCount`    | Number        | 12                 | 点赞数量，由 Like 集合统计或定时同步。               |
| `createTime`   | Date          | 时间戳             | 评论创建时间。                                       |
| `updateTime`   | Date          | 时间戳             | 评论编辑时间。                                       |

### 4 like

| 字段名       | 类型   | 示例               | 说明                                         |
| ------------ | ------ | ------------------ | -------------------------------------------- |
| `_id`        | String | "like_001"         | 云数据库自动生成主键。                       |
| `commentId`  | String | "comment_001"      | 被点赞的评论 ID（核心字段）。                |
| `dishId`     | Number | 11                 | 冗余字段，评论所属菜品，用于统计“菜品热度”。 |
| `canteenId`  | Number | 3                  | 冗余字段，评论所属食堂，便于后台统计。       |
| `userId`     | String | "wx_openid_abc123" | 点赞用户的 OpenID，用于防止重复点赞。        |
| `createTime` | Date   | 时间戳             | 点赞时间。                                   |

### 5 favourite

| 字段名        | 类型   | 示例               | 说明                                   |
| ------------- | ------ | ------------------ | -------------------------------------- |
| `_id`         | String | "fav_001"          | 云开发自动主键。                       |
| `userId`      | String | "wx_openid_abc123" | 收藏行为的用户唯一标识（OpenID）。     |
| `dishId`      | Number | 11                 | 被收藏的菜品 ID（关联 Dish）。         |
| `dishName`    | String | "日式咖喱鸡排饭"   | 冗余字段，便于“我的收藏”页面快速展示。 |
| `canteenId`   | Number | 3                  | 菜品所属食堂，帮助用户按食堂分类收藏。 |
| `canteenName` | String | "百惠园食堂"       | 冗余字段，减少跨集合查询。             |
| `createTime`  | Date   | 时间戳             | 用户收藏的时间。                       |

### 6 user

| 字段名             | 类型   | 示例值          | 说明                                                         |
| ------------------ | ------ | --------------- | ------------------------------------------------------------ |
| `_id`              | String | "user_001"      | 云开发自动主键。                                             |
| `userId`           | String | "wx_openid_xxx" | 用户唯一标识（OpenID），用于登录、鉴权、关联评论/收藏/点赞。 |
| `nickname`         | String | "小明"          | 用户微信昵称或自定义昵称，用于显示。                         |
| `avatarUrl`        | String | 云文件 URL      | 用户头像。                                                   |
| `gender`           | Number | 1               | 微信返回，0未知 1男 2女。可选字段。                          |
| `favouriteCount`   | Number | 12              | 该用户收藏菜品数量（可选，用于快速展示“收藏数量”）。         |
| `commentCount`     | Number | 5               | 用户评论数量（可选，用于个人主页）。                         |
| `createTime`       | Date   | 时间戳          | 用户首次登录时间，由注册流程生成。                           |
| `phone`            | String | "13800138000"   | 用户手机号。                                                 |
| `tastePreferences` | String | "重口味"        | 用户的口味偏好                                               |
| `dormArea`         | String | "紫菘公寓"      | 用户居住的宿舍区域（如紫菘、韵苑、沁苑）                     |

### 7 newdish

| 字段名         | 类型          | 示例            | 说明                           |
| -------------- | ------------- | --------------- | ------------------------------ |
| `_id`          | String        | "newdish_001"   | 云数据库主键。                 |
| `suggestionId` | Number        | 1               | 业务主键，用于排序与追踪建议。 |
| `userId`       | String        | "wx_openid_xxx" | 提交的用户 ID。                |
| `dishName`     | String        | "蜜汁鸡排饭"    | 新增的菜品名称。               |
| `canteenId`    | Number        | 3               | 菜品所属的食堂 ID。            |
| `canteenName`  | String        | "百惠园食堂"    | 冗余字段，减少前端额外查询。   |
| `price`        | Number        | 13.5            | 价格                           |
| `description`  | String        | "补充菜品信息…" | 用户补充信息。                 |
| `images`       | Array<String> | 图片数组        | 支持上传菜品照片。             |
| `createTime`   | Date          | 时间戳          | 提交时间。                     |
